Privacy Policy

Effective date: October 30, 2026

This policy describes the Security Research Lab informational website and the intended operation of a private API security research integration. The integration is not currently offered to external users.

1. Information collected by this website

This static website has no sign-in, contact form, analytics scripts, advertising trackers, or application cookies. We do not directly collect personal information through the website. GitHub Pages hosts the site and may process technical access information under GitHub's privacy statement.

2. Intended API research data

Subject to approval and applicable program rules, security tests may process limited API responses and metadata associated with accounts and resources controlled by the researcher or explicitly authorized for testing. Relevant information may include test account identifiers, test Pins or Boards, permission settings, request and response metadata, and temporary access credentials.

3. Purpose and access

Research data is intended solely to verify access controls, document reproducible security behavior, and submit responsible vulnerability reports to the applicable security program. The integration is private and does not provide an external-user service. We do not sell API data or use it for advertising, profiling, or marketing.

4. Credentials and data security

API access tokens and app secrets are not intended to be stored in the public repository or published on this website. Testing should use access restricted to authorized accounts and private local storage. Only the minimum data needed to demonstrate a finding should be retained.

5. Retention and deletion

Temporary testing data should be deleted when it is no longer needed for reproducing or responsibly reporting a security issue, subject to applicable program instructions. If unrelated personal data is unintentionally encountered, testing will stop; the data will not be retained or shared, and the exposure will be reported to the relevant program.

6. Sharing and third parties

Information necessary to report a confirmed issue may be submitted to the applicable vulnerability disclosure or bug bounty program. The website is hosted by GitHub Pages. No other third-party service is integrated into this website at present.

7. Inquiries and updates

For non-sensitive questions about this policy, use the project's GitHub Issues page. Issues are public: please do not post personal information, tokens, or vulnerability details there. This policy will be updated if the project begins collecting data through a public-facing app or changes its research data practices.
